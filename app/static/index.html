THE HIGH-LEVEL VIEW

An agent inside
a controlled workflow.

AGENT

Understand & investigate

Gemini on Vertex AI reads the question, calls the CMS lookup and definition tools, and returns a structured explanation with references.

WORKFLOW

Check & pause

LangGraph checks the evidence and routes the draft. Personal estimates and incomplete data need a specialist. Execution pauses for a human.

REVIEWER

Edit & decide

A person reviews the data, edits the reply, and approves or returns the draft. The workflow resumes and records that decision.

UIPATH

Cloud integration in progress

The coded-agent workflow can be packaged with the UiPath SDK. Automation Cloud and Action Center are not connected yet.
